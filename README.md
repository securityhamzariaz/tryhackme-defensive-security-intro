# 🛡️ TryHackMe – Defensive Security Intro (Cyber101)

## Overview

This repository documents my hands-on learning experience with the **Defensive Security Intro** room on TryHackMe. The lab introduces defensive security operations through a simulated banking environment called FakeBank.

The exercise focuses on identifying suspicious activity, investigating threats, containing attacks, gathering threat intelligence, and creating incident reports.

## 🎯 Objectives

- Understand the role of a Security Operations Center (SOC).
- Investigate suspicious login activity.
- Identify potential attacker behavior.
- Perform incident containment.
- Explore threat intelligence.
- Document security incidents.

## 🔍 Lab Tasks

### 1. Security Monitoring & Alert Investigation
- Investigated suspicious login attempts.
- Examined security alerts.
- Identified suspicious activity targeting the `/login` page.

### 2. Incident Containment
- Identified the compromised user account.
- Disabled/locked the affected account to prevent further unauthorized access.

### 3. Threat Intelligence
- Investigated the threat actor **ShadowFigures**.
- Explored the group's attack patterns and targeting.
- Reviewed known indicators and threat information.
- Updated the threat intelligence record with incident findings.

### 4. Incident Reporting
- Reviewed incident information.
- Identified incident details and severity.
- Prepared a formal incident report based on the investigation.

## 📚 Key Takeaways

This lab helped me understand how defensive security teams investigate alerts, contain compromised accounts, maintain threat intelligence, and document incidents in a structured manner.

It reinforced the importance of timely detection, effective containment, and accurate incident reporting in cybersecurity operations.
